## Reglas rápidas

- Los cambios de documentación se hacen en Linear, no en estos punteros.
- El esquema de la base sigue siendo la fuente de verdad técnica: si cambia, se actualiza la migración y el documento de arquitectura en el mismo PR.
- Las actas se llenan con datos reales; no se inventan asistencias ni acuerdos.
- Los enlaces a Linear y GitHub se mantienen en las issues y PRs.
